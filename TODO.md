# MyNotepad Roadmap

## Milestone 1: Basic editor window
- Create main form
- Add menu bar
- Add central editor control
- Add File > New, Open, Save, Save As, Exit

## Milestone 2: File state handling
- Track current file path
- Track dirty/unsaved state
- Update window title
- Prompt before destructive actions

## Milestone 3: Editing features
- Undo
- Cut/copy/paste
- Select all
- Keyboard shortcuts

## Milestone 4: Polish
- Status bar
- Word wrap option
- Font selection
- Basic app icon

## Future
- Syntax coloring
