# TxtItNow

MyNotepad is a small Windows Notepad-like text editor built with C#, .NET 10, and WinForms.

## Version 1 goals

- New file
- Open `.txt` files
- Edit text
- Save
- Save As
- Detect unsaved changes
- Prompt before closing with unsaved changes
- Basic menu bar and keyboard shortcuts

## Future ideas

- Syntax highlighting
- Find and replace
- Status bar with line/column
- Recent files
- Font settings
- Encoding options

## Non-goals for v1

- Tabs
- Rich text formatting
- Plugin system
- Syntax highlighting
- Cloud sync
